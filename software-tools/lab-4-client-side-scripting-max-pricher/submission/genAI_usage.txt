The Logic (JavaScript)
To make the "In-Person" vs. "Remote" logic work, add this script to your project. It listens for changes on the event_modality dropdown and toggles the visibility of the other fields.

JavaScript
function toggleModalityFields() {
    const modality = document.getElementById('event_modality').value;
    const locationField = document.getElementById('location_wrapper');
    const remoteUrlField = document.getElementById('remote_url_wrapper');
    const attendeesField = document.getElementById('attendees_wrapper');

    // Show attendees once a modality is picked
    attendeesField.classList.remove('d-none');

    if (modality === 'In-Person') {
        locationField.classList.remove('d-none');
        remoteUrlField.classList.add('d-none');
    } else if (modality === 'Remote') {
        remoteUrlField.classList.remove('d-none');
        locationField.classList.add('d-none');
    }
}
Why I used d-none:
Bootstrap’s d-none class is a quick way to set display: none. By wrapping your specific inputs in a div (like location_wrapper), we can hide the entire label and input field together so the form stays tidy.
